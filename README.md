# 观澜｜跨平台资产看板

靳世辰的AI辅助开发个人项目，面向作品展示的独立虚拟数据演示版。

## 功能

- 六个平台的资产汇总，支持USD、CNY、HKD、GBP展示币种切换。
- 持仓搜索、按平台筛选、市值与盈亏排序、跨账户同类资产合并。
- 虚拟净值走势，以及资金流调整后的参考盈亏计算器。
- 缺失数据保留未知，避免将本金转入或重复持仓计为收益。

## 项目分工

本人负责需求设计、业务及指标口径梳理、结果核验与迭代反馈；代码实现由Codex辅助完成。

## 数据说明

全部金额、持仓、价格、汇率及历史序列为虚拟样本；不代表真实资产或当前市场行情。演示不含私人账户信息、API密钥、真实接口或交易功能。六个平台展示不等于六个自动API连接，原项目采用只读API与手工录入相结合。
